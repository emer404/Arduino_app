# Arduino_app

Sitio web para controlar Arduino (encender y apagar).

## Demo
https://arduinoapp.netlify.app/

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Características
- Interfaz moderna para control de Arduino
- Botones de encendido y apagado
- Indicador visual del estado
- Registro de acciones con timestamps
- Diseño responsivo
